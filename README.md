
# Python Finance Tracker

A command-line personal finance application developed using Python.

## Features

- Add income and expenses
- Calculate current balance
- Categorise expenses
- View transaction history
- View spending summaries by category
- Validate user input
- Save transactions using JSON

## Technologies Used

- Python 3
- JSON
- Python Standard Library
- Visual Studio Code

## How to Run

1. Open the project folder in a terminal.
2. Run: python3 main.py
3. Follow the on-screen menu.
